Work through these tutorials to learn `Drasi` by building complete, runnable
applications. Each tutorial lives in
[`tutorials/`](https://github.com/drasi-project/drasi-dotnet/tree/main/tutorials)
and embeds the Drasi continuous-query engine directly in a .NET app — real data
sources, continuous queries, and reactions, with no separate server to run.
