Welcome to the documentation for **`Drasi`**, the .NET library that embeds
the [Drasi](https://drasi.io) continuous-query engine in your application.

## Where to start

- **[Getting started](getting-started/).** Install `Drasi` and run your first
  continuous query.
- **[Concepts](concepts/).** The change-driven model: sources, continuous queries,
  and reactions.
- **[Guides](guides/).** Task-focused walkthroughs: generic host, in-process
  sources and reactions, plugins, streaming, configuration, and errors.
- **[API reference](api/).** Every method on the `Engine` class.
- **[Examples](examples/).** The Quickstart, Hosted, and Plugins samples in this
  repository.
